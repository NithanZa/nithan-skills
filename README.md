# nithan-skills

Cursor skills for phased feature work and clear writing.

- `planning` writes `phase{N}-[phasename].md` files in the project's plan directory.
- `follow-plan` implements one phase, checks its acceptance criteria after tests pass, and stops.
- `follow-plan-all` implements the remaining phases in order and stops on the same blockers.
- `write-clearly` makes human-facing writing concise, natural, and well organized.

Each skill is `skills/<name>/SKILL.md`.
